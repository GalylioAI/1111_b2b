# 1111.tn — B2B Price Intelligence Platform

B2B price-intelligence SaaS by **Galylio** for Tunisian e-commerce shops.  
Track competitor prices across 62+ sites (Mytek, Tunisianet, Spacenet, Zoom, Batam, Darty…).

## Structure

| Folder | Stack | Description |
|--------|-------|-------------|
| [`web/`](./web/) | Next.js 16 · Tailwind v4 · TypeScript | Web dashboard |
| [`mobile/`](./mobile/) | Flutter 3 · Dart | Mobile app (Android / iOS) |

## Quick start

### Web
```bash
cd web
npm install
npm run dev       # http://localhost:3000
```

### Mobile
```bash
cd mobile
flutter pub get
flutter run
```
